# ADR-048 — Positioning statement + embargo language (stub)

## Status

**Proposed** — authored at HAUSSMANN genesis from Gate B evidence; the decision **content** is produced by mission P0.1 and ratified at **DP2**. This stub fixes the decision *space* so P0.1 opens with the question sharp.

## Context

All three synthetic cold-readers failed or barely passed the 30-second test; the definition arrives after the poetry; ≥3 proprietary terms precede the first concrete example (H1) `[D coldreads]`. The hero's "the **open** coordination protocol" is FALSE under the LatticeProtocol counsel embargo (claims #2) while the same page's "opening progressively" is honest. "aDNA" collides with *ancient DNA* for life-science readers; the "Compliance" label collides with health-compliance (N10). The engineer's split verdict — "7/10 for the standard, 3/10 for the network" — suggests the mechanism is sellable and the network framing is the debt.

## Decision space

1. **The one-sentence definition** — must contain a category noun a stranger knows (candidates from the evidence: "an open standard + folder convention for project knowledge that both humans and AI agents can navigate"), placed before any lyric register. Hero mode options from the dossier distribution: manifesto (23–40 words) · terse one-liner · **definition-as-hero** (the W3C/EIPs mode, new to the corpus) · content-as-hero.
2. **Audience naming** — explicit (the instrument requires it): primary = teams running agentic coding tools on real projects; the E-audience (public-good/rare-disease) named as mission, not as segment sprawl.
3. **The NOT-line** — e.g. "not a product, not a service, not a database — plain files you own."
4. **Embargo language pair** — pre-embargo-lift: the "opening progressively" family sitewide, never "open protocol"; post-lift variant staged for a copy-swap.
5. **Collision dispositions** — ancient-DNA: a first-screen disambiguation or deliberate acceptance (recorded); Compliance label: rename (e.g. "Provenance & audit") or scope-note.

## Recommendation (to be tested, not assumed)

Definition-as-hero or definition-first-manifesto; audience explicit; the code block stays above the fold (it out-communicated the prose in every cold read). The human panel at P0.1 O4 is the arbiter — ≥4/5 unaided passes.

## Consequences

Every copy/IA/voice mission (P1.1, P1.2, P2.2, P2.5, P4.5) inherits one sentence as north star; the embargo pair makes protocol truth a copy-swap instead of a redesign when counsel rules.
