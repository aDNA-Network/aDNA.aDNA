# Ethereum — GARNIER inspection, 2026-09-15

## Captured

[D] [Public page](https://ethereum.org/en/); native Chromium desktop 1440×900 and mobile 375×812, light preference and reduced motion. Reviewed both fold and subsequent-frame PNGs in `how/campaigns/campaign_garnier/evidence/research/native/ethereum__{desktop,mobile-lg}__{fold,next}.png`. The desktop illustration and event banner place the main statement near the bottom of the first screen. On mobile the first task remains below the fold. The following screen explains an ownership claim in plain language. This is a counterexample to treating install-above-fold as a universal property of strong sites.

[D] Hero count includes the visible headline and its first synopsis, excluding actions, navigation and metadata. Section count is a bounded heading diagnostic, not a full-page visual census. See [[reference_set_garnier_20260915]] for exact limitations and comparison rules.

## Lift for aDNA

[I] Preserve aDNA's warm public-good identity while making present-day ownership and voluntary sharing explicit. Pair the mission with a concrete way to inspect or contribute, after readers understand the mechanism. This is a proposed application to GARNIER, not a claim that this site's visual choices caused successful outcomes.

## Avoid

[I] Do not borrow network-scale claims, financial language, giant initial artwork or event promotions that displace the first task. A chosen exemplar can offer both a useful lesson and a pattern we should refuse.

## Reviewer reads

[I] One executor applied three existing heuristic lenses; these are not independent reviews or participant results.

- **Design Critic:** The image supplies a distinct identity but consumes much of the opening view.
- **Anti-Bloat Editor:** Shorten the route between purpose and a useful action.
- **Information Architect:** Task verbs such as learn, use and build can orient readers if their destinations are distinct.
