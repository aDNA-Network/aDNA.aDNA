## Lift for aDNA

[I] Give the quickstart one executable task and link a separate API/specification reference. Show prerequisites, the expected file result and an immediately adjacent recovery path. Make the phone path teach the same first task even if its composition changes. This is a proposed application to GARNIER, not a claim that this site's visual choices caused successful outcomes.

## Avoid

[I] The historical AVOID finding concerns combining tutorial and reference on every page. Borrow task grouping, not that mixture. Do not describe an illustrative terminal panel as proof that our copied command completed.

## Reviewer reads

[I] One executor applied three existing heuristic lenses; these are not independent reviews or participant results.

- **Design Critic:** Type and alignment establish hierarchy without many containers.
- **Anti-Bloat Editor:** Do not make readers scan the entire product directory to start one task.
- **Information Architect:** Test equivalent task reachability across desktop and mobile; stacking alone is not equivalence.
