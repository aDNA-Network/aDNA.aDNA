# Hugging Face — GARNIER inspection, 2026-09-15

## Captured

[D] [Public page](https://huggingface.co/); native Chromium desktop 1440×900 and mobile 375×812, light preference and reduced motion. Reviewed both fold and subsequent-frame PNGs in `how/campaigns/campaign_garnier/evidence/research/native/huggingface__{desktop,mobile-lg}__{fold,next}.png`. This capture has a marketing hero before trending content, unlike the old registry-as-hero description. Mobile retains the two hero actions and stacks the artifact groups. The small hero screenshot is less readable than the actual item rows below it.

[D] Hero count includes the visible headline and its first synopsis, excluding actions, navigation and metadata. Section count is a bounded heading diagnostic, not a full-page visual census. See [[reference_set_garnier_20260915]] for exact limitations and comparison rules.

## Lift for aDNA

[I] Show a small curated selection of real vault artifacts with public author/steward attribution, status and a clear inspection action. Use consistent metadata so a visitor can compare entries without opening every page. This is a proposed application to GARNIER, not a claim that this site's visual choices caused successful outcomes.

## Avoid

[I] Avoid manufactured activity, inflated counts and empty category grids. Do not copy the colorful card treatment into every section. Raw DOM extraction includes clipped menu items; a count of matching elements is not a count of visible choices.

## Reviewer reads

[I] One executor applied three existing heuristic lenses; these are not independent reviews or participant results.

- **Design Critic:** The real item rows carry more useful detail than the decorative catalog preview.
- **Anti-Bloat Editor:** Prefer a few useful entries over a second broad community promise.
- **Information Architect:** Organize by understandable object/task categories, with deeper browse available.
