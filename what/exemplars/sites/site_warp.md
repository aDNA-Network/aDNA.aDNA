# site_warp — Warp (warp.dev)

> **A currency-drift case study more than a craft exemplar.** Curated as "dark-native developer polish" — but the 2026 site has pivoted to a **light-first enterprise-agentic register**: "The open platform for automating development." The dark-native terminal identity now lives in the product, not the marketing surface. Headless capture 2026-08-16 (`campaign_haussmann/evidence/dossier/captures/warp/`).

## Captured (rubric)

- **Hero:** ~30 words — "The open platform for automating development" + "Infrastructure to build, measure, and interact with agents across your SDLC — so you ship more and spend less." Category-abstraction + ROI clause; CTAs "Start Automating" / "Download Warp Terminal."
- **Dark-mode reality (capture):** under dark emulation the page **renders light** — white field, black headline, one lavender product band. The premise this site was picked for has drifted; the terminal-craft residue is a monospace **ticker-tape strip** ("HOST OR WARP-HOST · CONNECT ANY TOOL · OWN YOUR DATA · ANY INFERENCE PROVIDER").
- **Proof:** product-UI screenshot (an agent-activity dashboard, not a terminal), logo wall (Anthropic, OpenAI, Docker, Google…), 3 named testimonials with titles — and **stat counters that render "0K Active Developers / 0% of Fortune 500" without JS**. Large mid-page sections came back as empty gray blocks headless (JS/video-gated content).
- **Install (the good part):** a footer "**Get Warp today**" **platform matrix** — macOS `brew install --cask warp`, Linux .deb/.rpm/AUR/Flathub with per-arch buttons, Windows `winget install Warp.Warp` — every path copy-able, honest, one screen.
- **Density:** enterprise-SaaS ~9 sections, 5-column footer, pricing + "Book a demo" surfaces. Tonal ~30.

## Lift for aDNA

- **The one thing to steal: the platform install matrix** — one compact block, every OS/arch path as a real command with copy affordance. The multi-platform extension of the [[site_bun]] command-in-hero for aDNA's install/quickstart page.
- The **monospace ticker of commitments** — a terminal-flavored accent that carries values ("own your data") without a manifesto section.
- Named testimonials with real titles (not logos alone).

## Avoid

- **JS-dependent proof** — counters that read "0" and sections that render blank without JS are exactly the no-JS failure aDNA's gates exist to prevent (Haussmann launch checks; cf. [[site_cratesio]]'s SPA shell).
- **The drifted hero register** — "open platform for automating development" is the same adjective-abstraction fold [[site_vercel]]'s AVOID hardened against; install demoted to the footer while the fold sells category words.
- Treat any "dark-native" premise as perishable — re-verify at inspection time (corpus currency finding, third instance).
