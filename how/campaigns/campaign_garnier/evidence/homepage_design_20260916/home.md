# Project knowledge, organized for AI.

aDNA (Agentic DNA) is an open standard for organizing a project's files. Three folders and plain Markdown give people and AI agents a shared map.

Start a local workspace with Git and Claude Code.

[Get Started](/get-started) [Read the standard](/reference/specification)

$ `git clone https://github.com/aDNA-Network/aDNA.git ~/aDNA && cd ~/aDNA && claude`
Copy

Not a product or service — no server, no signup; aDNA itself sends nothing.

The standard that gives it that shape is open. Your files stay on your machine. Your AI tool has its own data handling.

[Open source on GitHub](https://github.com/aDNA-Network/aDNA) · MIT-licensed · [the standard, versioned and public](/reference/specification)

## A project you can inspect

### Folder structure

```
aDNA.aDNA/
├── CLAUDE.md      Agent instructions
├── STATE.md       Work in progress
├── what/          Knowledge and decisions
├── how/           Plans and procedures
└── who/           People and roles
```

### `CLAUDE.md` excerpt

The site you are reading uses this structure. Its instruction file tells an agent how to work:

```
# CLAUDE.md — aDNA.aDNA

## Standing Orders

1. **Phase gates are human gates.** Never auto-advance between campaign phases without explicit user approval.
```
[Read the full instruction file](https://github.com/aDNA-Network/aDNA.aDNA/blob/main/CLAUDE.md)
These are written instructions. The structure does not enforce an agent’s behavior.

## Knowledge worth passing on

Think of it as AI DNA: the instructions, decisions and knowledge an agent can read.

DNA carries our biological inheritance. The knowledge we choose to share can become a cultural inheritance for AI. We want people to build, question and improve it together, for the good of all.

Share what you choose. Keep the rest private. Democratic stewardship is the goal; [Stanley Bishop stewards the project today](/about/).
