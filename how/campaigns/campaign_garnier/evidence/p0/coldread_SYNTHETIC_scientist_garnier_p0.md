### Mechanism

**aDNA supplies structured files and instructions that an agent follows.** Knowledge belongs in `what/`, operations in `how/`, and people/governance in `who/`. The agent reads governance and current state, follows directory routing, and selects relevant context from topic indexes containing token estimates. Session close-outs preserve completed work and instructions for the next session. [Design rationale](https://adna.network/reference/design-rationale), [specification v2.5, §10](https://adna.network/reference/specification/10-context-library).

The “convergence model” narrows scope through campaign → mission → objective. Routing files tell the agent which branches to follow; task decomposition keeps the working context within a proposed 75% window budget. These are prescribed selection procedures. The rationale explicitly describes collision prevention as cooperative conventions rather than enforced locking. [Convergence model](https://adna.network/learn/concepts/convergence), [collision-prevention rationale](https://adna.network/reference/design-rationale#7-collision-prevention).
