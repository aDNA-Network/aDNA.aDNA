# Consumer instrument contract v1

[I] Preparatory instrument work runs while isolated P0.1 scoring finishes; P0.2 cannot close before P0.1. This contract and its controls are authored together, before prescreen outcomes. It does not change the VITRUVIUS instrument or add CI policy.

## Populations and semantics

- [D] Word census: the seven routes in word_budgets, using the existing reading_census.mjs over local built Markdown twins. Its prose exclusions and whole/prose split remain authoritative for that metric. A missing twin is an instrument failure. Overage is WARN, never an automatic rewrite or failure. The owner is artifacts/genesis/word_budgets.md; targets are not duplicated in another policy file.
- [I] Vocabulary census: the same seven frozen production HTML main elements, including headings/cards, with DOM text concatenation across inline markup. Exclude script/style, pre/code, blockquote/q, hidden and aria-hidden nodes and retain every exclusion receipt. The eight exact generic terms are a lexical screen; inflections and contextual voice rules require manual adjudication. A quotation exemption requires genuine attribution, not a container used to hide marketing. Banned authored prose is FAIL; zero matches proves only this population. Offline DOM extraction is not a computed-visibility or accessibility-tree claim.
- [D] Contextual voice review also reaches lives/lived, context-democracy headings, unexplained opening-progressively wording, first-screen counters, circular definitions, status legends and internal shorthand. No generic-word zero can clear those rules. Unsupported claims remain blocking against evidence; no lexical instrument verifies a claim.
- [D] Complete tracked component population: git ls-files over site/src/components, layouts, pages and styles, all extensions. complete_component_census.json lists 96 files: 83 Astro, eight TS, five CSS; no JS/JSX/TSX currently occurs. Existing component_token_census.mjs reaches only 32 Astro component/layout files. Supplemental lexical receipts cover every tracked file, including pages and CSS/TS; they are candidate inventories, not computed token conformance. Comments/string literals and token-definition/JS-palette sources are reported, not silently omitted. P3.1 adjudicates whether an available semantic token can replace each candidate without visual harm.
- [I] Token controls invoke the existing census in a disposable tree. A deliberately planted bypass must be detected; production candidates are advisory until adjudicated. ADR-059 stays validators-only. No generic token parser or provider bar is copied.
- [I] Capture contract requires the declared route×viewport×theme set, unique cells, expected HTTP status, actual reached page, present PNG/axe receipt and observed theme equal requested theme. A checkpoint is missing website evidence. The baseline harness sets class/theme but does not persist computed theme per cell; its captures and manual inspection establish requested-theme evidence, not a future strict telemetry assertion. Later capture instruments must retain observed theme, and fresh-load as well as desktop-resize diagram states. Supplemental P0.2 theme receipts are separate from the immutable scoring pack.
- [I] Reader contract is reader_protocol.md v1, frozen before prescreens. Synthetic contexts receive only public stimuli and role tasks. Two independent key calibrators judge the six anonymous fixture answers before participant scoring. No synthetic timing or proportion is a human result.
- [I] Adjectives-per-claim: REJECT as a blocking metric in v1. Claims have semantic scope and attribution that a word counter cannot adjudicate. P1 records sentence-level capability assertions and evidence links, then a human-readable adjective annotation if useful; no manufactured denominator or ratio is published. This resolves the genesis omission by explicitly declining an unvalidated metric, rather than treating missing output as zero.

## Controls and ownership

[D] evidence/p0/instruments/consumer_probe.mjs uses the installed Playwright DOM and the existing component census; it makes no external request and mutates only disposable raw fixtures. Its twenty controls cover valid/invalid prose, split inline headings, permitted quotation/code with receipts, adjacent prose, missing main, advisory overage, missing JSX/route/duplicate, wrong theme, missing PNG/axe, checkpoint and six token families. reading_census.mjs retains its own eighteen self-tests. The exact outputs are instrument_controls.json and reading_controls.txt.

[I] New reusable contract gaps are staged in provider_pattern_proposal.md for Vitruvius through the federation wrapper. This consumer experiment is not an adopted WebForge pattern or a site gate. Accessibility consequence: counters cannot justify smaller text, removed prerequisites, lost headings or inaccessible diagrams; equivalent text and reflow stay acceptance conditions.
