## VisualDNA bundle proposal

[I] Consumer-owned bundle for `adna_network`, consuming the existing VisualDNA v1.0 schema and composition rules through the wrapper. Declare palette anchors using this site's semantic tokens, five slot compositions, reference assets owned by this project, invariants, optional renderer compatibility and provenance. Do not depend on the provider's unpromoted web-card extension. Retain the existing warm pixel landscape language; no generated people, institutions, charts or false evidence.

The bundle is authored and schema-validated in P3.1 before any generation. Hero/category/empty-state/graph-frame assets each declare their slot, purpose, alt treatment, credit, dimensions, theme behavior and payload cost. A diagram's data and labels remain code/text; the graph frame may supply atmosphere without conveying unsupported topology. Decorative assets use empty alt; informative assets get a complete equivalent. Every animated variant has a static version. Abstract-only generation remains optional at D-4; no new image was generated in genesis.

## What this pass could not see

No new layout, font, asset or doctrine has been accepted or implemented. The proposal still needs low-fidelity reader checks before high-fidelity craft. Reference likeness is not an acceptance criterion.
