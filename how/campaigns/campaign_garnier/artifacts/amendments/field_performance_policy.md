# Field performance and insufficient-data exception

[I] The operator approved this exception as part of DP1 on 2026-09-15. It changes GARNIER's publication criterion only; it does not change provider bars, VITRUVIUS scoring or HAUSSMANN's evidence policy.

Classify each required mobile field metric (LCP, INP, CLS) as PASS, FAIL, INSUFFICIENT_DATA or COLLECTION_UNVERIFIED. Record source, observation window, route/origin scope, build attribution, provider sufficiency signal and sample metadata where exposed. Respect a provider's withheld small sample; do not invent a universal minimum or treat an origin aggregate as route proof. Unknown sufficiency is not PASS.

A valid field failure remains blocking. COLLECTION_UNVERIFIED remains blocking. An INSUFFICIENT_DATA exception is eligible only when all lab/performance budgets pass on the named candidate; mounted transport and an actual collector receipt are verified; the report explicitly says which field metrics remain unmeasured; and the launch decision records the exception, owner and due date. No score or public statement may call this field-green. Collection access failure is not low traffic.

P4.1 prepares the evidence. P5.3 presents the exact exception in the separate publication gate. Approval here establishes the policy, not a deploy GO. Stanley owns ensuring the follow-up is assigned; Rosetta is the executor inside this vault. Schedule the first field review for launch date +30 calendar days, then monthly until sufficient data is available. At each review, retain unknown status if observations remain insufficient. A subsequently observed failure creates an assigned remediation item immediately and is surfaced to the operator. No automation, monitoring account or external message is installed by this amendment.

Negative controls: remove sample/sufficiency metadata (must not produce PASS); mark a measured metric failing (must block despite excellent lab results); remove the collector receipt (must block exception eligibility). The controls exercise GARNIER's decision record, not a fabricated field dataset.
