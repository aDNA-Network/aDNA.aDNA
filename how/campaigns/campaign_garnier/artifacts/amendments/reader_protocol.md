# Decisive-reader protocol v1

[I] This contract implements approved D-6. P0.2 freezes wording, answer keys, stimulus build and scoring rules before any result is read. It is separate from VITRUVIUS v1.1 and HAUSSMANN's panel.

## Synthetic prescreens

Run one fresh-context prescreen per engineer, funder and scientist at P0 and again on the P1 storyboard/copy candidate. Supply only the persona brief, captured public pages/links and tasks; omit campaign rationale, author conclusions and expected answers. Use distinct contexts and record supplied context, runtime and tool access. Label every output SYNTHETIC and [D-syn]; these are task simulations, not measured three-second human perception or statistically independent human evidence. Preserve the primed genesis reads unchanged. No synthetic pass substitutes for recruitment or a human threshold.

## Formative humans before visual production

The operator supplies at least one consenting newcomer from each decisive class. Test the P1 low-fidelity candidate before DP3 using the same tasks below; collect confusion verbatim. This is formative evidence with three individual observations, no percentage success claim. Fix each material confusion or carry an explicit disposition into the DP3 human exit decision. Formative participants are excluded from the final cold-reader cohort. Agents do not recruit or send invitations. Missing humans keep this item owed; do not silently proceed into visual production.

## Stimulus and timing

Freeze one build and viewport per participant; record device, theme, URL, build identity and prior familiarity. Show the loaded homepage for three seconds, conceal it, then ask the short questions with no explanation or feedback. Restore it for three minutes of self-directed browsing, then collect the role tasks. Record the two sequential windows honestly: the same participant sees the first window before the second; these are not independent cohorts. Capture timing deviations and assistive-technology use; accommodate the participant and report protocol differences instead of excluding disability. Store consent-safe de-identified verbatims; do not collect contact information in public evidence.

## Answer key

Three-second prompt, all classes: “What does this project provide, and what can you do with it now?” Pass requires a reusable structure/standard for organizing an AI agent's context and a present action such as inspect, clone or use the published graph. Exact terminology is unnecessary. Calling it a trained frontier model, an established multi-institution federation, or asserting current democratic ownership unsupported by the stimulus is a failure. Annotate inability to answer separately from an incorrect claim.

Three-minute engineer task: find the exact initial runnable command or local file example, name its prerequisite, and explain where context/governance lives. Pass requires all three located artifacts to match the pinned stimulus; merely saying “open source” fails.

Three-minute funder task: identify the named steward, distinguish something available from a stated plan, and find the present contribution/contact ask. Pass requires all three and no invented endorsement or adoption.

Three-minute scientist task: explain the mechanism, locate its source/lineage, and identify what evaluation is actually available or explicitly absent. Pass requires all three; the DNA metaphor alone is insufficient.

P0.2 prepares two anonymized calibration answers per role: one valid answer expressed without project jargon and one plausible answer that confuses aspiration with fact. Two scorers must apply the key correctly before scoring participants. Disagreement is preserved and adjudicated against the published key, with the reason recorded.

## Final panel and retesting

P5.1 uses at least five new humans per decisive class, operator recruited. Predeclare the final cohort size before reading outcomes; do not stop at a favorable denominator. Require at least ceil(0.8×n) passing participants per class in EACH window; publish raw numerator/denominator and failure reasons. Both windows must pass, and each three-minute answer must satisfy all its role's checks. Retain clinician/researcher, OSS contributor and autonomous-agent tasks from the existing bench as separate regression evidence; do not merge them into the decisive denominator.

On failure, correct the surface and repeat the affected class with a new cold cohort of at least five; preserve the first result. A homepage mechanism/hierarchy change affects all classes and requires a full repeat. Do not pool successful participants across versions. The stimulus remains frozen throughout a run. P5.1 remains queued until actual human records exist.
