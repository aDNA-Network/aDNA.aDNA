Install from the terminal

Same installer, same result. Pick your system:

$ curl -fsSL https://adna.network/install.sh | sh -s -- --code YOUR-CODE

replace YOUR-CODE with the invite code you were given · needs python3 · no admin password required

No code? Run it without --code — it prints your join request as text to send by hand instead.

What happens, in order

  1. 01

    The installer sets up your machine

    It downloads the networking software, checks it against a fingerprint written into the installer itself, and creates a private key that is generated on your machine and never leaves it.

  2. 02

    Your code sends the join request for you

    The installer submits your request automatically — nothing to copy, nothing to paste, and it contains no secrets. (No code? It prints the request as text instead, and you send it by hand.)

  3. 03

    A person approves it — then rerun the same command

    Approval is a human decision every time; nothing about joining is automatic. Once approved, the same command fetches your certificate, checks it against a fingerprint that shipped inside the installer, and you are on the network.

What it does

  • Installs Nebula, pinned to one version and checked against a fingerprint baked into the installer
  • Generates a keypair on your machine, readable only by you
  • Writes its configuration in your own user folder
  • Submits your join request with your invite code (or prints it to send by hand), then exits

What it does not do

  • Ask for your admin password, or need one
  • Send anything about your machine anywhere
  • Change your firewall, DNS, or router
  • Connect you to the network on its own
  • Require an AI assistant, an account, or a signup

Prefer to read it before running it? The installer is a short shell script — open it in a browser first. It downloads one file and refuses to run it if the fingerprint does not match.
